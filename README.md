# menico/homebrew-tap

Homebrew formulae and casks.

## cpx — run several Claude Code accounts side by side

```bash
brew tap menico/tap
brew trust menico/tap        # Homebrew requires this for any third-party tap
brew install cpx             # the command
brew install --cask cpx-app  # the menu-bar app
```

Homebrew refuses to load anything from a third-party tap until you trust it —
*"Refusing to load formula menico/tap/cpx from untrusted tap"* means the
`brew trust` line above has not been run. It is asked once per machine and
covers both the formula and the cask.

Note the app is `cpx-app`, not `cpx`. A formula and a cask sharing one name
makes every `brew` command ambiguous, and `brew upgrade` then leaves the
command unlinked.

Updating:

```bash
brew update
brew upgrade cpx
brew upgrade --cask cpx-app
```

Source, issues, and documentation: <https://github.com/menico/cpx>

The formulae here are generated by `scripts/release.sh` in that repository —
edit it rather than these files.
