# menico/homebrew-tap

Homebrew formulae and casks.

```bash
brew tap menico/tap

brew install cpx           # the cpx command
brew install --cask cpx-app  # the cpx menu-bar app
```

Updating:

```bash
brew update && brew upgrade cpx
```

Contents are generated by [`scripts/release.sh`](https://github.com/menico/cpx)
in the source repository — edit that rather than the formulae here.
